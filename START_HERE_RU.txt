A-BEATS 1.2.0 — БЫСТРЫЙ СТАРТ ДЛЯ WINDOWS 10/11 x64

1. Распакуйте весь архив в отдельную папку, например C:\A-BEATS.
2. Для установки в профиль Windows запустите INSTALL_A-BEATS.bat.
   Программа скопируется в %LOCALAPPDATA%\Programs\A-BEATS,
   создаст ярлыки и откроет первый запуск.
3. Если хотите запускать без установки, используйте START_A-BEATS.bat.
4. При первом запуске потребуется Интернет: программа подготовит Python,
   установит библиотеки и скачает FFmpeg.
5. В приложении выберите папки с битами и обложками, создайте MP4,
   задайте расписание и подключите свой YouTube-канал через Google OAuth.

ВАЖНО:
- Этот архив содержит готовый исходный Windows-пакет с установщиком/bootstrap.
  Самостоятельный A-BEATS.exe и Setup.exe не собраны в этой среде Linux.
- Для получения Setup.exe запустите BUILD_EXE.bat на Windows 10/11 x64
  с Python 3.12 x64; при установленном Inno Setup скрипт создаст Setup.exe.
  Альтернатива — загрузить проект в собственный GitHub и запустить workflow
  из .github/workflows/build-windows.yml (инструкция в BUILD_WINDOWS_ON_GITHUB.md).
- Для реальных публикаций владелец канала один раз настраивает Google Cloud OAuth.
- Не передавайте никому OAuth JSON и папку %LOCALAPPDATA%\A-BEATS\tokens.
- Используйте только аудио и изображения, на которые у вас есть права.
