# Changelog

## 1.2.0 — 7 ноября 2026

- Шифрование OAuth-токенов средствами Windows DPAPI для текущего профиля пользователя.
- Безопасная атомарная запись токенов; совместимость с ранее созданными незашифрованными token-файлами.
- Устранено обращение к Tkinter BooleanVar из фонового потока при пакетной загрузке.
- После применения дискографии пересчитываются и описания, использующие `{track_name}`.
- Добавлены интеграционные тесты реального FFmpeg-рендера в Full HD и 4K.
- Добавлены тесты экспорта CSV, неоднозначных обложек и хранилища токенов.
- Добавлена конфигурация pytest; сборка Windows теперь запускает unittest и pytest.
- Добавлена защита от случайной повторной отправки после обрыва связи: неопределённые загрузки требуют сверки с YouTube Studio и ручного подтверждения.

## 1.1.0 — 7 ноября 2026

- Добавлен установщик для текущего пользователя и удаление приложения без удаления пользовательских данных.
- Добавлены сценарии сборки Windows EXE и Setup.exe, а также GitHub Actions workflow для Windows x64.
- Добавлены журналирование с ротацией, резервная копия очереди и более безопасное сохранение состояния после загрузки.
- Добавлены локальный дневной защитный лимит API-загрузок и миграция старого формата очереди.
- Добавлена обработка неоднозначных пар аудио/обложка и корректных переходов DST.
- Добавлена загрузка кастомной миниатюры YouTube после отправки видео.

## 1.0.0 — 7 ноября 2026

- Первый MVP: импорт аудио и обложек, генерация MP4, шаблоны метаданных, расписание, YouTube OAuth/API и CSV для ручного режима Studio.
