# Как получить Setup.exe через GitHub Actions

Этот пакет содержит готовый сценарий Windows-сборки, но сам Setup.exe должен быть скомпилирован на Windows x64.

1. Создай пустой репозиторий на GitHub.
2. Распакуй архив A-BEATS и загрузи в репозиторий все файлы и папку `.github`.
3. Открой вкладку **Actions**. Если GitHub предложит включить Actions, разреши.
4. В списке workflow выбери **Build A-BEATS for Windows**.
5. Нажми **Run workflow** и дождись зелёной галочки.
6. В завершившемся запуске скачай артефакт **A-BEATS-Windows-x64**.
7. Внутри будут папка `A-BEATS` с приложением и `A-BEATS-Setup-1.2.0-x64.exe`.

Сборка запускает unit- и интеграционные тесты, включая проверку FFmpeg-рендера, компилирует Windows-приложение, добавляет FFmpeg runtime и создаёт установщик Inno Setup. Google OAuth в артефакт не включается: каждый пользователь подключает собственный Google Cloud OAuth client.

Не загружай в публичный репозиторий свои `client_secret*.json`, OAuth tokens, `settings.json`, `queue.json`, аудио, обложки и готовые видео. В `.gitignore` уже перечислены основные приватные локальные файлы.
