A-BEATS 1.2.0 — ПЕРВЫЙ ЗАПУСК

1. Распакуй весь архив в отдельную папку.
2. Для установки и создания ярлыков запусти INSTALL_A-BEATS.bat. Можно также запустить START_A-BEATS.bat прямо из папки.
3. При первом запуске программа подготовит Python 3.12 (если его нет и доступен winget), библиотеки и FFmpeg. Нужен Интернет.
4. Выбери папку с битами и папку с обложками. Повторный импорт добавляет только новые файлы.
5. Если обложка не сопоставилась автоматически, выбери строку и нажми «НАЗНАЧИТЬ ОБЛОЖКУ».
6. Впиши артиста и нажми «НАЙТИ ТРЕКИ АРТИСТА», если хочешь использовать названия из каталога Apple. Двойным щелчком по строке название можно изменить вручную.
7. Выбери 1080p или 4K, укажи папку MP4 и нажми «СОЗДАТЬ MP4».
8. Для публикации один раз настрой Google Cloud OAuth (инструкция в README.md), подключи канал и нажми «ЗАЛИТЬ ЧЕРЕЗ API».
9. Укажи время и интервал публикаций. По умолчанию используется America/New_York, первая публикация — завтра в 18:00, интервал — 24 часа.

Важно:
- Google OAuth требует твоего личного входа и разрешения на YouTube-канал.
- YouTube API имеет ограничения квоты. A-BEATS использует внутренний защитный лимит 90 загрузок в день.
- Режим Studio открывает YouTube Studio и создаёт CSV. Дальнейшая загрузка выполняется вручную.
- Программа не автоматизирует скрытые клики в браузере.
- Используй только аудио и изображения, на которые у тебя есть права.

Очередь, настройки и OAuth-токены сохраняются в %LOCALAPPDATA%\A-BEATS.
