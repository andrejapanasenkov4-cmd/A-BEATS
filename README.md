# A-BEATS 1.2.0 — Windows Desktop

Локальное Windows-приложение для пакетной подготовки Type Beat-видео и планирования публикаций на YouTube. Интерфейс на русском языке. Поддерживаются Windows 10/11 x64, Full HD и 4K.

## Что умеет приложение

### Подготовка контента
- Пакетный импорт аудио: MP3, WAV, FLAC, M4A, AAC, OGG, WMA, AIFF, ALAC, OPUS, APE, CAF, AMR, 3GP.
- Поиск аудио и обложек выполняется также во всех вложенных папках выбранных каталогов.
- Импорт обложек: PNG, JPG/JPEG, WEBP, BMP, TIFF, GIF.
- Автоматическое сопоставление по имени файла; суффиксы `_cover`, `_artwork`, `_thumbnail`, `_thumb` игнорируются. Если точного совпадения нет, используется осторожное сравнение имён; неоднозначные пары остаются для ручного назначения.
- Если найдено несколько возможных обложек, приложение не угадывает: строка остаётся без пары, обложку можно назначить вручную.
- Повторный импорт папок добавляет только новые аудиофайлы, не дублируя существующие задания.
- Двойной щелчок по строке позволяет изменить название трека.

### Рендер
- MP4 1920×1080 или 3840×2160, 30 fps.
- H.264, CRF 18, AAC 320 kbps, `yuv420p`, `faststart`.
- Обложка заполняет кадр без обрезки; лишнее пространство дополняется чёрными полями.
- Без водяных знаков A-BEATS.
- Готовые MP4 сохраняются в выбранную папку. Повторный рендер задания обновляет его текущий MP4 в той же папке.

### Названия и метаданные
- Шаблон заголовка поддерживает `{artist}`, `{beat_name}`, `{title}`, `{track_name}`.
- Шаблон описания поддерживает `{artist}`, `{beat_name}`, `{track_name}`.
- Теги вводятся через запятую; перед отправкой ограничиваются лимитом YouTube.
- Поиск названий композиций по артисту через публичный Apple/iTunes Search API. Приложение получает до 200 результатов каталога, фильтрует их по имени артиста и убирает дубли.
- Каталог Apple не гарантирует полную дискографию. Найденные названия можно исправить двойным щелчком по строке. Названия треков не дают прав на чужие записи, обложки или товарные знаки.

### Расписание
- Время первой публикации и интервал в часах.
- Часовые пояса IANA, включая `America/New_York`, `America/Chicago`, `America/Los_Angeles`, `Europe/London`, `Europe/Berlin`, `Europe/Moscow`.
- Интервал 24 часа сохраняет местное время публикации при обычном переходе на летнее/зимнее время.
- Несуществующее местное время в момент весеннего перехода DST обнаруживается и блокируется, чтобы не поставить видео на неверный час.
- Время переводится в UTC перед отправкой YouTube.

### YouTube
- OAuth 2.0 через официальный YouTube Data API v3.
- Подключение нескольких доступных YouTube-каналов Google-аккаунта; у каждого канала хранится отдельная локальная OAuth-сессия.
- Возможность отключить канал и удалить локальный токен.
- Загрузка видео в статусе `private` с `status.publishAt` для отложенной публикации.
- Настройка уведомления подписчиков.
- Установка кастомной миниатюры из обложки с преобразованием в JPEG 1280×720 и сжатием до лимита YouTube.
- Каждое задание хранит свой YouTube video ID отдельно для каждого канала. Повторный запуск не отправляет уже загруженное задание повторно на тот же канал.
- Если соединение оборвалось в момент загрузки и неизвестно, принял ли YouTube видео, повторная отправка блокируется. Пользователь проверяет YouTube Studio и через кнопку «ПРОВЕРИТЬ СБОЙ» либо указывает найденный Video ID, либо вручную разрешает повтор после проверки отсутствия видео.
- Очередь сохраняется после каждого успешного видео; создаётся резервная копия `queue.json.bak`.
- Внутренний защитный лимит A-BEATS — 90 попыток `videos.insert` за день по тихоокеанскому времени. Это оставляет запас относительно стандартного лимита проекта Google; если другой софт использует тот же проект, фактическая квота может закончиться раньше.

### Режим YouTube Studio
- Открывает YouTube Studio и экспортирует CSV-манифест с файлами, метаданными и расписанием.
- Загрузка в Studio выполняется вручную. A-BEATS не автоматизирует скрытые клики в браузере и не обходит ограничения платформы.

## Установка и запуск

### Самый простой вариант

1. Распакуйте весь архив в отдельную папку, например `C:\A-BEATS`.
2. Для установки в профиль Windows запустите `INSTALL_A-BEATS.bat`. Он скопирует приложение в `%LOCALAPPDATA%\Programs\A-BEATS`, создаст ярлыки в меню «Пуск» и на рабочем столе и запустит первый запуск. Либо просто запустите `START_A-BEATS.bat` из распакованной папки.
3. При первом запуске установщик подготовит Python 3.12 (если его нет и доступен winget), виртуальное окружение, библиотеки и FFmpeg.
4. После установки откроется приложение. Следующие запуски не скачивают зависимости повторно, пока не изменится `requirements.txt`.
5. Для удаления программы запустите `UNINSTALL_A-BEATS.bat`. Локальные настройки, очередь, токены и MP4 останутся в `%LOCALAPPDATA%\A-BEATS`; удалите эту папку вручную только если действительно хотите удалить пользовательские данные.

Нужен Интернет для первоначальной установки Python/библиотек/FFmpeg и для сетевых функций. Если winget недоступен, установите Python 3.12 x64 с python.org и повторите запуск.

### Сборка EXE и Setup.exe на Windows

1. Установите Python 3.12 x64.
2. Запустите `BUILD_EXE.bat`.
3. Скрипт установит зависимости, запустит тесты, подготовит FFmpeg и соберёт каталог `dist\A-BEATS`.
4. Если установлен Inno Setup 6, скрипт также соберёт установщик в `installer_output`.
5. Для ручной сборки установщика откройте `BUILD_INSTALLER.iss` в Inno Setup 6 и нажмите Compile.

Распространяйте весь каталог `dist\A-BEATS` или `A-BEATS-Setup-1.2.0-x64.exe`, а не один EXE-файл. Установщик включает FFmpeg runtime; ознакомьтесь с `THIRD_PARTY_NOTICES.md`.

### Автоматическая Windows-сборка в GitHub Actions

В репозитории есть `.github/workflows/build-windows.yml`. После загрузки проекта в свой GitHub-репозиторий откройте **Actions → Build A-BEATS for Windows → Run workflow**. По завершении скачайте артефакт `A-BEATS-Windows-x64` со сборкой приложения и Setup.exe. Для этого потребуется собственный GitHub-репозиторий.

## Подключение YouTube — настройка владельца канала

Google OAuth нельзя настроить за владельца канала без его участия. Это единственная обязательная авторизация, которую пользователь выполняет самостоятельно.

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте проект.
2. Включите [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com).
3. Настройте Google Auth Platform / OAuth consent screen. Если приложение находится в режиме Testing, добавьте Google-аккаунт в Test users.
4. Создайте OAuth Client ID типа **Desktop app** и скачайте JSON.
5. В A-BEATS нажмите **ПОДКЛЮЧИТЬ КАНАЛ**, выберите JSON и завершите авторизацию в открывшемся браузере.
6. Выберите нужный канал в списке. Если у Google-аккаунта несколько доступных каналов, приложение попробует получить их список.
7. Повторите подключение для дополнительных Google-аккаунтов при необходимости.

Не отправляйте никому OAuth JSON, токены или папку `%LOCALAPPDATA%\A-BEATS\tokens`. При отзыве доступа удалите канал из приложения или отзовите разрешение на странице безопасности Google.

## Квоты и ограничения YouTube

По актуальной документации Google, `videos.insert` имеет отдельный стандартный лимит 100 вызовов в день на API-проект; один вызов стоит 1 единицу в этом отдельном bucket. Другие методы API используют общий дневной пул квоты. A-BEATS ограничивает собственные попытки 90 в день, чтобы оставить небольшой запас, но не может видеть использование квоты другими приложениями проекта.

`status.publishAt` можно задавать только для приватного видео, которое ранее не публиковалось. Видео загружается как `private`, а публикацию в нужное время выполняет YouTube. Лимиты проекта, канала и доступность пользовательских миниатюр контролируются Google/YouTube и не гарантируются приложением.

Если Google вернул ошибку квоты, оставшиеся задания сохраняются. После сброса квоты можно снова запустить загрузку. Если время публикации для оставшихся заданий уже прошло, приложение остановит загрузку и попросит изменить дату, чтобы не опубликовать видео немедленно.

## Данные и конфиденциальность

`%LOCALAPPDATA%\A-BEATS` содержит настройки, очередь, резервную копию очереди, локальный журнал `a_beats.log` (ротация до 3 резервных файлов), историю локальных попыток загрузки, OAuth-токены и папку output. Аудио и обложки обрабатываются локально. Запросы каталога треков отправляются Apple/iTunes. При загрузке видео и миниатюр данные передаются YouTube после явного действия пользователя.

На Windows OAuth-токены шифруются средствами DPAPI для текущего профиля пользователя Windows и хранятся локально. Их нельзя перенести на другой Windows-профиль простым копированием. На не-Windows средах разработки DPAPI недоступен и используется незашифрованное локальное хранение. Защитите учётную запись Windows и диск (например, BitLocker) и не делитесь папкой данных. Приложение не собирает пароли Google и не содержит телеметрии.

## Проверка качества

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe -m pytest -q
```

Тесты проверяют сопоставление файлов, шаблоны, каталог треков, расписание, переходы DST, экспорт CSV, миграцию очереди, защиту от дубликатов, хранилище токенов и реальный FFmpeg-рендер в 1080p/4K. Перед реальным использованием проверьте OAuth и загрузку на тестовом YouTube-канале.

## Права на контент

Загружайте только музыку, обложки и визуальные материалы, на которые у вас есть права или разрешение. Название артиста или песни не означает одобрение артиста и не даёт права использовать чужую запись или изображение.
