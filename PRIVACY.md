# Конфиденциальность и хранение данных

A-BEATS — локальное desktop-приложение. Аудио, изображения и готовые MP4 обрабатываются на компьютере пользователя. Приложение не отправляет аудио/обложки в сторонний сервис для рендера и не собирает пароли Google.

Сетевые операции:
- поиск названий треков — запросы к публичному Apple/iTunes Search API;
- OAuth и публикация — Google OAuth и YouTube Data API;
- первоначальная установка — загрузка библиотек Python и FFmpeg runtime.

Папка данных: `%LOCALAPPDATA%\\A-BEATS`. В ней хранятся `settings.json`, `queue.json`, резервная копия `queue.json.bak`, локальный счётчик попыток YouTube API, OAuth-токены в `tokens` и подготовленные MP4 в `output` (если используется папка по умолчанию).

На Windows OAuth-токены шифруются средствами DPAPI для текущего профиля пользователя Windows и хранятся локально. Зашифрованные токены привязаны к профилю Windows и не переносятся на другой профиль простым копированием. На не-Windows средах разработки DPAPI недоступен, поэтому там используется незашифрованное локальное хранение. Защитите учётную запись Windows, включите шифрование диска (например, BitLocker) и не передавайте папку `tokens` другим людям. Не публикуйте OAuth client secret JSON. Удаление локального канала в A-BEATS удаляет локальный токен, но для полной отмены разрешения дополнительно отзовите доступ на странице безопасности Google.

Загрузка видео на YouTube происходит только после явного нажатия кнопки загрузки и OAuth-авторизации. A-BEATS не автоматизирует скрытые действия браузера и не отправляет видео без действия пользователя.

Приложение не содержит аналитики и телеметрии.
